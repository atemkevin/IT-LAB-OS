# IT Lab OS — Product Requirements Document

## Vision
IT Lab OS is a personal technical learning operating system that helps a learner become practically competent in IT through active practice, troubleshooting, projects, and measurable mastery.

## Core loop
Learn → Practice → Test → Troubleshoot → Build → Review.

## Target user
A self-directed learner progressing from IT fundamentals toward Network Engineering, Cybersecurity, and AI Automation.

## Killer interaction
“Don’t tell me what to watch. Give me something to fix.”

## MVP goals
- Personalized learning path
- Skill-centered curriculum
- Lessons and practice
- Quizzes and evidence
- Deterministic troubleshooting simulator
- Daily mission engine
- AI Mentor
- Projects
- Contextual notes
- Mastery analytics

## Non-goals
No public social network, instructor marketplace, paid courses, arbitrary remote shells, unrestricted VMs, native mobile app, or enterprise multi-tenancy in MVP.

## Curriculum
0 Orientation
1 Computer Fundamentals
2 Operating Systems
3 Networking
4 Linux
5 Windows / Active Directory
6 Python / Automation
7 Cybersecurity
8 Web Security
9 Cloud
10 Docker / DevOps
11 AI / Automation
12 Specialization

## Specializations
- Network Engineer
- Cybersecurity
- AI Automation

## Mastery formula
Knowledge 30% + Practice 20% + Troubleshooting 25% + Project 15% + Retention 10%.

## Mastery states
0–29 Not Started; 30–49 Developing; 50–69 Practicing; 70–84 Proficient; 85–100 Strong.

## MVP definition of done
Auth, onboarding, curriculum, prerequisites, lessons, practice, quizzes, evidence, mastery, dashboard, daily missions, troubleshooting simulator, AI Mentor, projects, notes, progress, mobile responsiveness, security controls, tests, production build.
