# IT Lab OS — Screen & UX Specification

## Primary navigation
Dashboard, Learning Path, Skills, Daily Mission, Labs, Projects, Notes, Progress.
Secondary: AI Mentor, Profile, Settings.

## Dashboard
Must show: greeting, current path, overall mastery, today's mission, continue learning, weak skills, recent activity, study time, domain progress.

## Learning Path
Visual progression of skills with prerequisite state, mastery score, status, domain, and estimated time.

## Skill page
Sections: Why it matters, objectives, prerequisites, Learn, Practice, Test, Troubleshoot, Build, Review.

## Lesson page
Short content, examples, common mistakes, understanding checks, hands-on task, explicit completion.

## Practice
Objective, context, requirements, success criteria, hints, submission, feedback.

## Quiz
Single choice, multi-select, scenario. Never preload correct answers to client.

## Daily Mission
30/60/120-minute modes. Mission contains title, duration, objective, context, tasks, hints, success criteria, reflection.

## Troubleshooting
Terminal-like simulator with scenario, evidence, allowed commands, hint ladder, diagnose and finish actions. Commands are deterministic and simulated.

## AI Mentor
Modes: Tutor, Coach, Troubleshooter, Interviewer, Reviewer.

## Projects
Objective, prerequisites, requirements, deliverables, acceptance criteria, skills, submission, review.

## Notes
Markdown, search, tags, pinning, links to learning objects.

## Progress
Overall mastery, domain mastery, skill dimensions, learning time, activity, weak skills, evidence.

## Mobile
Bottom nav: Home, Learn, Mission, AI, More. Troubleshooting terminal remains the main interaction surface.

## Visual direction
Technical, premium, focused, modern. Avoid childish gamification and excessive decorative effects.

## Accessibility
Target WCAG 2.2 AA where practical: keyboard navigation, visible focus, semantic HTML, accessible labels, contrast, reduced motion, non-color-only statuses.
