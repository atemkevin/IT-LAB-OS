## Objective
Build a real working personal technical learning operating system, not a mockup or CRUD demo.

## Core loop
Learn → Practice → Test → Troubleshoot → Build → Review

## MVP safety boundary
Troubleshooting is deterministic/simulated. Do not execute arbitrary learner commands on the application host.
